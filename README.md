# Store App

This is the project from [The Odin Project](https://github.com/TheOdinProject) curriculum — a store application built with **Ruby on Rails**, focusing on MVC architecture, routing, controllers, views, Active Record, database interactions, and CRUD operations.

## Features

- Product listing and product details
- Create, edit, update, and delete products
- Product validation
- Rails routing and RESTful routes
- Reusable ERB partials
- Active Record models and database interactions
- CRUD operations using Rails controllers
- Form handling with `form_with`
- Database migrations and schema management

## Skills Learned

### Ruby on Rails

- Rails application structure
- MVC architecture
- Controllers and actions
- Routes and RESTful routing
- Rails views with ERB
- Partials and local variables
- Rails helpers such as `link_to` and `form_with`
- Controller callbacks with `before_action`
- Strong parameters
- Rails console

## Challenges

- Understanding the Rails MVC architecture
- Understanding how requests travel through routes, controllers, and views
- Learning Rails conventions and generated route helpers
- Understanding controller callbacks such as `before_action`
- Working with ERB templates and Rails view helpers
- Understanding Rails partials and local variables
- Understanding Rails strong parameters
- Getting familiar with Rails generators and command-line tools
